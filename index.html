A skin for Video.js v10

VIDEOBOY

A video player built like a handheld. Full colour while it plays.
The moment it stops, the screen becomes a four-tone dot-matrix panel.

Press X or Space to play. Pause to see the screen transform. Explore the console controls below.

Theme

01 · The idea

The screen is the skin.

Controls sit in the console below the picture, leaving the video unobstructed. When playback stops, the image shifts into a four-tone dot-matrix display.

02 · Anatomy

Every part of the handheld is a real control.

Nothing on the console is decoration. Each part is a working control and shows its state on its face.

    05 · Sizes

    Designed for different player sizes.

    The console adapts to the available width, rearranging its controls when space is limited while keeping the handheld layout recognisable. Keys stay full size at every width.

      07 · Accessibility

      Usable by everyone.

      • Keyboard and focusEvery control can be reached and used from the keyboard. A 3 px focus ring, offset from each key, stays visible on every shell colour. The menu closes with Escape.
      • Screen readersEvery key has its own name and shortcut. The dot-matrix screen is decorative and hidden from screen readers; a status announcer speaks play, pause, seek and volume changes.
      • Contrast and forced coloursLabels, timecodes and screen text reach at least 6.6:1 and key icons 5.7:1, in all three themes. In Windows high contrast mode the console redraws itself in system colours.
      • Reduced motionMenu › Motion: Auto follows your system setting; Full and Reduced override it and are remembered. Reduced removes the pixel mosaic, the blinking and the logo drop.
      • CaptionsSet in a plain system font on dark plates, never in the pixel font, so they stay readable over bright and dark footage.
      • Touch targetsPlay, mute and system keys are at least 40 px. The D-pad responds anywhere in its 90 px circle. The seek strip, grille and menu rows are 38 to 44 px tall.

      Testing and reports

      0 automated axe-core violations in 96 runs in Chromium: WCAG 2.2 A and AA plus best-practice rules, three themes, three player widths and ten states, and this page in every theme at desktop and phone widths. Run them yourself with npm run test:a11y in the repository. Raw results: a11y-report.json. What a screen reader is given: a11y-tree.txt.

      Automated checks catch a lot, but they are not a full accessibility audit. Manual testing with screen readers (NVDA, VoiceOver) and in Firefox and Safari has not been done yet.

      08 · Install

      Add VIDEOBOY to your project.

      Source on GitHubDownload the skin (zip)

      1. Get the skin. Download the zip or clone the repository, and copy its src folder into your project as videoboy.
      2. Install the packages. 
        # Video.js v10, and the Mux element if you stream from Mux
npm i @videojs/html @videojs/mux-video
      3. Import the skin and stylesheet. Add the third line only if you use Mux. 
        import './videoboy/skin';
import './videoboy/videoboy.css';
import '@videojs/html/media/mux-video';
      4. Add your video inside the VIDEOBOY skin. A plain <video> works in place of <mux-video>. 
        <video-player>
  <videoboy-skin data-theme="tangerine" poster-time="36">
    <mux-video src="https://stream.mux.com/YOUR_PLAYBACK_ID.m3u8" playsinline crossorigin="anonymous"></mux-video>
  </videoboy-skin>
</video-player>

      Video from another domain always plays. If that server does not allow cross-origin access (CORS, the browser rule for reading media from other sites), the pause screen uses a simpler colour filter instead of the dot-matrix. The skin is open source under Apache-2.0.
